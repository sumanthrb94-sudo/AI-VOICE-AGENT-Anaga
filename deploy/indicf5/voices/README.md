Reference clips live here, two files per voice:

    anaga_te_f.wav    10-20s, clean, ONE speaker, no music, no background
    anaga_te_f.txt    that clip's EXACT transcript

The transcript must match the audio word for word. IndicF5 aligns against it,
and a wrong transcript yields confident, fluent, wrong prosody — which is harder
to notice than a crash and worse on a live call.

Only clone a voice you have written permission to clone. This directory is
gitignored so a real person's voice is never committed.
